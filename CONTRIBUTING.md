# Bugs and suggested fixes

Thanks for using Tokmizer. The source is published so you can read it, build it and check what it does.

## Found a bug?

Open an issue with the bug report form. Please include:

- the Tokmizer version (`tkr --version`) and your agent (Claude Code, Codex, Cursor…);
- your system (macOS, Linux, Windows);
- the command, what Tokmizer showed and what you expected;
- a reduced sample of the output if it helps.

Remove any secret, token, private path or customer data from what you paste.

## Have a fix in mind?

Describe it in the issue, or paste a diff. Pull requests are closed on this repository: the maintainer reviews each suggestion and applies the changes himself, rewritten or not, when they fit. Nothing is merged automatically.

By sharing a suggested fix, you agree that it may be used, changed and published as part of Tokmizer under the project's licences, and you confirm you have the right to share it.

## Security problems

Do not open a public issue. Write to contact@tokmizer.com, see [SECURITY.md](SECURITY.md).

## Building it yourself

```
npm install
npm run build
npm test
```
