# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email **contact@tokmizer.com** with:

- a description of the issue and its impact;
- the steps or a proof of concept to reproduce it;
- the Tokmizer version (`tkr --version`), your operating system and the AI tool involved.

We acknowledge reports within 5 working days, keep you informed while we work on a fix, and credit you in the release notes unless you prefer otherwise. Please give us a reasonable delay to ship a fix before any public disclosure.

## Scope

In scope: the code in this repository, the published `@tokmizer/plugin` npm package, the native launcher and the install scripts.

Out of scope here: the tokmizer.com website and its API. Report issues with them to the same address; they are handled separately.

## Supported versions

Only the latest published version of `@tokmizer/plugin` receives security fixes. Update with `tkr update` or `/tkr-update`.
